مرکز افزونه مثل مخزن وردپرسِ همین سرور است: بسته را یک‌بار نصب می‌کنید، بعد آن را به یک یا چند دسته اضافه می‌کنید. از آن لحظه تمام وب‌سایت‌های آن دسته افزونه را دارند؛ لازم نیست سایت‌به‌سایت نصب شود.

کلاس افزونه

from mohsen_sdk import BasePlugin, plugin_get, plugin_set, merged_plugin_settings

class Plugin(BasePlugin):
    slug = "sms"
    name = "پیامک"

    def site_context(self, website, request):
        return {"enabled": True}

    def on_form_submit(self, website, form_name, data):
        if form_name != "contact":
            return None

    def admin_panel(self, request, website):
        return {"title": "پیامک", "html": "
پنل سایت
"}

    def handle_admin_post(self, request, website):
        plugin_set(website, self.slug, "settings", {"provider": "log"})

    def category_admin_panel(self, request, category, assignment):
        return None

    def handle_category_post(self, request, category, assignment):
        assignment.settings = {"provider": "log"}
        assignment.save(update_fields=["settings"])

قلاب‌ها

  • site_context دیکشنری قالب، زیر plugins.slug.
  • head_html رشته‌ای برای انتهای head. با احتیاط.
  • on_form_submit بعد از ذخیره پیام تماس.
  • admin_panel و handle_admin_post فرم داخل ویرایش هر سایت.
  • category_admin_panel تنظیم پیش‌فرض برای کل دسته، در صفحه خود افزونه.

ذخیره داده

  • plugin_get(website, slug, key, default) و plugin_set داده مخصوص یک سایت.
  • merged_plugin_settings(website, slug) تنظیم دسته را با تنظیم سایت ترکیب می‌کند. مقدار خالی سایت، پیش‌فرض دسته را پاک نمی‌کند.

نمایش در قالب مشتری

خروجی HTML را با markupsafe.Markup برگردانید فقط اگر خودتان همه ورودی‌ها را با html.escape امن کرده باشید. نمونه صفحه‌ساز همین کار را می‌کند. قالب مشتری این را چاپ می‌کند:

  {{ plugins.page_builder.html }}
{% endif %}{% endverbatim %}

امنیت

افزونه با همان کاربر سرویس اجرا می‌شود و محدود به سندباکس نیست. این تصمیم عمدی و شبیه وردپرس است. زیپ ناشناس را نصب نکنید. پنل، پسوند فایل، مسیر .. و قابل import بودن کلاس را چک می‌کند، ولی منطق افزونه را محدود نمی‌کند.

چرخه افزودن به دسته

  1. زیپ را در مرکز افزونه بارگذاری کنید.
  2. در صفحه افزونه دسته‌ها را تیک بزنید، یا از ویرایش دسته افزونه را انتخاب کنید.
  3. سایت جدیدی لازم نیست ساخته شود؛ سایت‌های فعلی همان دسته بلافاصله افزونه را می‌گیرند.
  4. برای تنظیم هر مشتری، صفحه ویرایش همان وب‌سایت بلوک افزونه را نشان می‌دهد.
