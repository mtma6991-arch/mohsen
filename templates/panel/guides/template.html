قالب یک فایل زیپ است که پنل آن را استخراج، اعتبارسنجی و به یک دسته وصل می‌کند. سایت‌های آن دسته می‌توانند همین قالب را انتخاب کنند. موتور رندر Jinja2 سندباکس است؛ کد پایتون داخل قالب اجرا نمی‌شود.

نمونه جواهر نمونه گوشی

ساختار زیپ

template.json
layout/base.html
pages/home.html
pages/about.html
pages/contact.html
assets/style.css
assets/fonts/…

اگر همه چیز داخل یک پوشه باشد هم قبول است، به شرطی که template.json در همان پوشه باشد. مسیرهای ..، لینک نمادین و پسوندهای غیرمجاز رد می‌شوند.

template.json

{
  "name": "آتلیه زرین",
  "slug": "jewelry-atelier",
  "version": "1.0.0",
  "author": "نام شما",
  "description": "یک خط توضیح",
  "homepage": "home",
  "pages": [
    {"slug": "home", "title": "خانه", "file": "pages/home.html", "in_menu": true},
    {"slug": "contact", "title": "تماس", "file": "pages/contact.html", "in_menu": true}
  ],
  "demo_data": {"products": [{"name": "گردنبند", "price": "۱۰۰۰", "note": "", "metal": "طلا"}]}
}
  • slug قالب و صفحات فقط حروف کوچک انگلیسی، عدد و خط تیره.
  • file باید به .html ختم شود و داخل زیپ وجود داشته باشد.
  • homepage یکی از slugهای صفحات است. همان صفحه روی / باز می‌شود.
  • demo_data داده نمونه است. در ویرایش سایت، با «محتوای اختصاصی JSON» قابل جایگزینی است.

اگر دسته آن افزونه را نداشته باشد، شرط برقرار نمی‌شود و طرح پیش‌فرض قالب می‌ماند. برای پیامک چیزی را در صفحه چاپ نکنید؛ کلید API هرگز به قالب نمی‌رسد.

قواعد ایمنی که پنل چک می‌کند

  • حداکثر حدود ۸۰ مگابایت زیپ و ۲۰۰ مگابایت پس از باز شدن.
  • پسوند مجاز: html, css, js, json, svg, png, jpg, jpeg, webp, gif, ico, woff, woff2, txt, md, map, webmanifest.
  • فایل py داخل قالب رد می‌شود.
  • نحو Jinja قبل از ذخیره کامپایل می‌شود. خطا همان لحظه نشان داده می‌شود.
  • اتو-اسکیپ روشن است. HTML خام مهمان را تزریق نکنید.

حداقل قالب سالم

یک pages/home.html که از layout/base.html ارث می‌برد کافی است. نمونه کامل را دانلود کنید و فقط متن و CSS را عوض کنید؛ سپس زیپ را در «قالب‌ها» برای دسته مورد نظر بارگذاری کنید.
