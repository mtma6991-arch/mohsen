# دستور mohsen

پس از نصب، `sudo mohsen` یا `sudo Mohsen` منو را باز می‌کند و **قبل از منو** آدرس واقعی ورود را چاپ می‌کند. همان رشته را در نوار مرورگر بگذارید. آدرس ساختگی مثل `http://SERVER/...` دیگر چاپ نمی‌شود.

نمونه خروجی:

```text
ورود پنل — این آدرس را عیناً در نوار مرورگر وارد کنید
  http://203.0.113.10:8787/web-pass/
  http://203.0.113.10/web-pass/
  نام کاربری: admin
  رمز عبور:   ********
```

آدرس از آی‌پی واقعی کارت شبکه، پورت پنل و web pass فعلی ساخته می‌شود. اگر دامنه پنل ثبت شده باشد، آدرس همان دامنه هم می‌آید. نام کاربری و رمز از `/root/mohsen-credentials.txt` خوانده می‌شود. با عوض کردن رمز یا web pass، همان فایل به‌روز می‌شود.

## منو

1. وضعیت سیستم
2. افزودن دامنه پنل (add domain)
3. نمایش دوباره اطلاعات ورود
4. تغییر رمز عبور مدیر
5. تغییر مسیر محرمانه (web pass)
6. راه‌اندازی مجدد سرویس
7. پشتیبان‌گیری در `/var/backups/mohsen`
8. حذف دامنه پنل
9. به‌روزرسانی از گیت‌هاب
10. حذف کامل پروژه
0. خروج

## دستورهای دقیق

```bash
sudo mohsen
sudo mohsen login
sudo mohsen update
sudo mohsen uninstall --yes
```

`sudo mohsen update` کد را از `https://github.com/mtma6991-arch/mohsen` شاخه `main` می‌گیرد و `install.sh` را اجرا می‌کند. پایگاه، رسانه و رمز مدیر پاک نمی‌شود.

`sudo mohsen uninstall --yes` حذف کامل است: سرویس، پیکربندی nginx محسن، دستور، `/opt/mohsen`، `/var/lib/mohsen`، `/etc/mohsen`، لاگ، پشتیبان، فایل رمز و کاربر سیستمی. خود بسته nginx حذف نمی‌شود. بدون `--yes` اسکریپت تأیید می‌خواهد و باید کلمه `uninstall` نوشته شود.

افزودن دامنه، رکورد را در پایگاه و در `/etc/mohsen/admin-domains.txt` می‌نویسد. nginx از قبل همه Hostها را به برنامه می‌دهد، بنابراین آی‌پی و دامنه همزمان کار می‌کنند. گواهی certbot اختیاری است.
